| D001 | M0 device testing on Pixel Fold | M001 | Profile capability gate determines the supported integration path | Detect MULTI_PROFILE, DOCUMENT_START_SCRIPT, WEB_MESSAGE_LISTENER at runtime via WebViewFeature.isFeatureSupported(). The bootstrap URL is authorised separately from remote game navigation. Service worker interception is tested and documented. | The spec requires proving that a native-supplied bootstrap reaches native content without executing upstream code. This is the safety guard against upstream migration overwriting existing progress on cold launch. | yes | agent |
| D003 | M04 archive import/export implementation | M004 | Archive format v1 uses .ihub ZIP with manifest and immutable blobs | Extension: .ihub. Container: ZIP with manifest.json (format version, archive ID, creation time, exporting app version, member paths/lengths/hashes, included instance/snapshot IDs, exclusions), game/instance records, snapshot envelopes, and immutable payload blobs. Adapters remain bundled/trusted application code. Imported definitions are inert until matched to an installed adapter. No auto-execute scripts. Unique destination filenames. Streamed import with bounded validation (512 MiB compressed, 1 GiB expanded, 10,000 entries, 8 MiB payload). Failed import leaves existing vault unchanged. | The spec defines the format in section 11.1. A portable ZIP-based format is standard, inspectable, and avoids proprietary binary formats. Manifest-based validation enables corruption detection. | yes | agent |
| D004 | M02 session controller implementation | M002 | Lifecycle ownership: SessionController owns WebView and profile lifecycle | SessionController owns the active WebView instance, profile binding, navigation epoch, and capture/restore state machine. On process death, recovery is through durable state (Room + vault), not WebView state. Renderer crash detaches and destroys the failed WebView, invalidates pending bridge requests, and shows recovery UI. | Spec section 6.2 requires the transition handling to belong in SessionController, not scattered Compose callbacks. Keeping the WebView outside transient composable branches prevents recreation on recomposition. | yes | agent |
