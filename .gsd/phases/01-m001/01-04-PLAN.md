# S04: SessionController Resilience

**Milestone:** M001
**Slice:** S04

**Goal:** Add four resilience capabilities to SessionController: (1) 60-second foreground capture cadence as a lifecycle-owned coroutine, (2) cold-start bootstrap integration using existing BootstrapDetector/PreLaunchSnapshot, (3) renderer crash detection via WebViewHost error callbacks triggering Degraded state, (4) process-death recovery by persisting recoveryState/lastCaptureAtMillis in GameInstance and restoring on app relaunch, plus (5) game-switching isolation that settles old sessions before opening new ones. All changes are confined to SessionController, WebViewHost, GameInstance schema, and HubDatabase with ~31 new unit tests.
**Demo:** Foreground capture bounded; renderer crash produces recovery UI; process recovery works; game switching isolated

## Must-Haves

- R012: 60-second cadence starts on Playing, fires at ~60s, cancels on state change, requestForegroundCapture() works as one-shot
- R013: open() runs BootstrapDetector, transitions to Playing on success, RecoveryRequired on failure, PreLaunchSnapshot fires asynchronously
- R014: WebView error callback triggers Degraded transition, RecoveryOverlay shown in RecoveryRequired state
- R015: cold-start reads DAO for recoveryState, persists recoveryState on Degraded, schema migration v1→v2 works
- R016: switching games settles old session, increments epoch, activates new game, no cross-game leakage
- ./gradlew :app:assembleDebug passes, all 10+31=41+ existing tests pass

## Proof Level

- This slice proves: strong

## Integration Closure

S04 consumes SessionController (S03), WebViewHost (S02), GameInstance DAO (S01), BootstrapDetector/PreLaunchSnapshot (M0). Produces: capture cadence API, crash auto-detection, process-recovery cold-start, game-switching orchestration. No new public APIs beyond what SessionController already exposes.
