# S03: Candidate Game Qualification

**Milestone:** M001
**Slice:** S03

**Goal:** Inspect candidate games (Shark Incremental primary, FE000000 secondary) to identify actual localStorage keys, serialization format, save cadence, readiness signal, and import path. Prove a capture→export→fresh-profile import→verify round-trip on-device using a disposable WebView profile. Deliver game definition JSONs, adapter implementations, a GameQualifier test harness, and a Compose UI displaying qualification results.
**Demo:** FE000000 (or Shark Incremental) is inspected: actual localStorage keys, serialisation format, save cadence, readiness signal, and import path are identified. A capture→export→fresh-profile import→verify round-trip is proven.

## Must-Haves

- 1. Both game definition JSONs parse correctly at load time and contain all required fields (schemaVersion, gameId, storageContext, saveCoverage, adapterId). 2. SharkIncrementalAdapter round-trips synthetic base64-JSON data without loss. 3. Fe000000Adapter round-trips synthetic gzip-wrapped data without loss. 4. GameQualifier reports QualificationResult.passed=true for at least Shark Incremental on the target device. 5. GameQualificationScreen displays per-game result cards with evidence lines. 6. ./gradlew :app:assembleDebug exits 0.

## Proof Level

- This slice proves: integration

- [x] **S03-T03**: GameQualifier test harness _(2d)_
  **Why:** The GameQualifier is the highest-risk component in S03 — it exercises the full capture→import pipeline on real WebView profiles. It creates a disposable profile, navigates to the game, captures the save via the adapter, imports into a fresh profile, and verifies the game loaded correctly. This is the core proof that the qualification pipeline works end-to-end.

  **Do:** Implement GameQualifier.kt in the `games/` package. The harness must: (1) Create a disposable profile via ProfileStore.getOrCreateProfile. (2) Bind a WebView via WebViewCompat.setProfile() before navigation. (3) Navigate to the game URL using the qualified bootstrap mechanism from S02 (or about:blank for synthetic testing). (4) Simulate progress by writing a synthetic save (or wait for autosave). (5) Capture via the adapter's capture() method. (6) Navigate to a fresh profile. (7) Import the captured save via the adapter's prepareRestore() + verifyLoaded(). (8) Read back the save key and compare. (9) Return a QualificationResult with per-stage pass/fail and evidence lines. Use CompletableDeferred for WebView callback bridging (S01/S02 pattern). Clean up disposable profiles in finally blocks. Write a JSON report to filesDir/ for machine-parseable evidence.

  **Done when:** GameQualifier.kt compiles and the build passes. The harness can theoretically run on-device to prove the round-trip (actual device execution is covered by UAT).
