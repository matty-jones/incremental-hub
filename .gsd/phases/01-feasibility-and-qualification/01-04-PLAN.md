# S04: Integrated Play-Capture-Restore Spike

**Milestone:** M001
**Slice:** S04

**Goal:** Prove the full vertical slice on real device: play Shark Incremental → capture its real autosaved save → destroy the source WebView → create a fresh profile → import the captured save → verify game progress is preserved. This proves both the data-preservation invariant (WebView.destroy() does not wipe profile localStorage) and the round-trip invariant (adapter import restores correct state into a fresh profile).
**Demo:** A minimal app that proves the full vertical slice: play FE000000 (or Shark) → capture snapshot → destroy WebView/process → fresh-profile restore → verify game progress is preserved.

## Must-Haves

- 1. IntegratedSpike.kt runs the full flow: navigate to Shark URL → wait for player ready → wait for non-empty shark_inc_save → capture via adapter → destroy source WebView → verify profile localStorage survived destroy → create fresh WebView bound to fresh profile → import captured save → verify restored save matches captured save. 2. UI shows per-stage PASS/FAIL with evidence lines. 3. JSON report written to filesDir/integrated_spike_report.json. 4. Build exits 0. 5. Activity registered in manifest.

## Proof Level

- This slice proves: integration

## Integration Closure

S04 wires together the GameAdapter interface (S03), ProfileStore (S01), and WebViewCompat.setProfile() (S01/S02) into a single end-to-end flow that no prior slice exercised: destroying the source WebView and then importing into a fresh profile.
