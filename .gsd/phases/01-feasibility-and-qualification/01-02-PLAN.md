# S02: Native-Origin Bootstrap Spike

**Milestone:** M001
**Slice:** S02

**Goal:** Prove that a native HTML bootstrap document served from app assets at a qualified storage origin can read existing localStorage and capture a pre-launch snapshot envelope before any upstream game JavaScript executes. Test both WebViewAssetLoader (primary) and loadDataWithBaseURL (fallback) mechanisms on the real Pixel Fold, report which produces a qualified origin, and display results in a native Compose screen.
**Demo:** A native HTML bootstrap document served from app assets loads at a qualified storage origin, reads existing localStorage, and captures a pre-launch snapshot before the remote game code executes.

## Must-Haves

- Bootstrap HTML asset exists at app/src/main/assets/bootstrap/native.html with inline JS that reads localStorage and posts a web message to native
- BootstrapDetector identifies at least one working origin mechanism (WebViewAssetLoader or loadDataWithBaseURL) and logs the qualified origin
- PreLaunchSnapshot captures a non-empty snapshot envelope (non-zero uncompressedBytes, valid SHA-256 of keys) from a synthetic localStorage key written to a test profile
- BootstrapScreen displays bootstrap detector results and pre-launch snapshot results with pass/fail badges
- BootstrapActivity is registered in AndroidManifest and launches BootstrapScreen
- ./gradlew :app:assembleDebug exits 0

## Proof Level

- This slice proves: device

## Integration Closure

BootstrapDetector feeds working-origin mechanism into PreLaunchSnapshot; both feed results into BootstrapScreen. Pre-launch snapshot ordering invariant (R008) is proven on device.

## Verification

- Logcat tags: BootstrapDetector, PreLaunchSnapshot. JSON report at filesDir/bootstrap_report.json. Native web message payload contains snapshot envelope (SHA-256, byte count, timestamp).
